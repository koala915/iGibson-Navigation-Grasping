## 1. 現在能跑什麼

### 常駐夾取服務（本次新增，定點夾取用）

```bash
python3 graspctl.py status     # 服務狀態、伺服角度、目前偵測是否新鮮
python3 graspctl.py grasp      # 夾一次，約 8.5 秒
python3 graspctl.py release    # 伸手、開爪、回 home（丟垃圾桶那一段）
python3 graspctl.py home       # 原地張爪回 E1，把物體放回桌上
```

在 `grasp/v23/` 底下執行，用系統 `python3`（3.6.9）即可，不必進 venv。
服務本體由 systemd 開機帶起（`grasp-service` + `grasp-vision`），開機後約 30 秒可用。

原理：`grasp_service.py` 呼叫 launcher 自己的 `build_ctrl_cmd()` 取得**完全相同的
參數**，再把 `GraspController.run` 換成等指令的迴圈。所有安全閘照跑，只是從「每次跑」
變成「啟動時跑一次」。42.3 秒裡有 34 秒是重複載入 torch／PyBullet／PPO／YOLO。

⚠ **服務活著時獨占 `/dev/myserial` 和相機。** 要用 `move_arm.py`、`bus_probe.py`、
`jetson_one_command_grasp.py` 之前一定要先：

```bash
sudo systemctl stop grasp-vision grasp-service
```

忘了停的症狀是「裝置打不開」，看起來很像硬體壞掉。

### 三姿態掃描（後備，物體不在 E1 視野時）

```bash
./graspscan.sh --accept-single-rotated-view
```

會自己停服務 → 跑 LEFT/E1/RIGHT 掃描與夾取 → 再把服務拉回來（`trap EXIT`）。
走這條要付完整的 23 秒啟動成本，所以只在 E1 看不到物體時用。

- Jetson 使用者固定是 `jetson`，**IP 每次開機都會變**，要當場查（`hostname -I`）。
- 完整環境在 `~/grasp_venv`（Python 3.8）。系統 `python3` 是 3.6.9，跑不動 torch。

  `progress.md`。torch 是 **CPU-only**（JetPack 4.6 沒有對應的 CUDA wheel），
  YOLO 推論在 CPU 上約 0.25 秒／張（`--imgsz 320`）。

  全套約 569 MB，跟常駐服務（約 1.3 GB）可以並存，還剩約 1 GB。
