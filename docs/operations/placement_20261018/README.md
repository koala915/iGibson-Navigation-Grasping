## 本次改動

- 放置模式：放置盒模型、停車 0.213 m、對準 −0.028、抵達報告檢查後才放開（10/18 稍早的 e407741）。
- 框外粗略靠近（同上）：校正範圍外的連續 3 幀推算位置只當驅動目標，永不觸發最後對準；0.80 m 內仍未實測即停。
- **先轉正**：暫時目標偏 12° 以上就原地以 1.0 rad/s 轉到 5° 內，再交給 PPO（0.78 rad/s 的上限會讓原地轉不動）。
- **E1 看不到就前挪**：E1 正常、連 4 幀新畫面完全看不到盒子時，收臂前挪 3 cm 再看，最多 2 次；看到盒子（即使位置不能用）或沒有新報告就不挪。只往前：里程計多算只會停短，停過頭時盒子會出現在畫面下緣。
- **夾爪卡住判斷**（`grasp/v23/x3plus_real_grasp.py`，`jaw_stall_repeats=3`）：只影響手臂已到位、夾爪單獨移動且沒有接觸監看的動作（放開張爪、空夾閉合）。夾物體的閉合走接觸偵測，與舊版逐筆比對 110／135／150／165° 四種接觸角，送出的指令完全相同。車上已部署（原檔備份 `x3plus_real_grasp.py.before_jawstall_20261018`）。

- **E1 讀數配對**（完整 4）：查詢落在兩張 E1 畫面之間時不再清掉上一筆新讀數；兩筆新讀數相隔 4 s 內、相差 8 mm 內才夾，條件不變。
