## 部署與恢復界線

10/16已在實機原稿加入獨立健康socket/影像心跳相容補丁，並啟用控制/視覺限定監督器，
相機受控故障可約12–15秒自動恢復；不是完整新版transport取代，也未啟用owner自動重啟。
此前Jetson `/tmp` 假硬體測試仍只代表離線驗證，不能與上述實測範圍混為一談。
詳見[10/16部署界線](../operations/HEALTH_COMPAT_RECOVERY_2026-10-16.md)。
感測服務可有限重啟；Serial 故障升級需新版 API、足夠 RAM、idle／空夾爪／巡航位、
沒有未知 checkpoint，且取得原子 restart-lock。
監督器每次開機最多主動重啟 owner 一次；重啟使 PID 與 odom 原點改變，
舊任務不能自動續跑，导航必須重新驗證／定位。
UI 停止不是伺服機立即斷電。系統完全無回應或實際運動無法確認時保留診斷，
不以強制重啟與自動動作掩蓋故障。
