## 已排除或尚不能宣稱的問題

- `obs_28_incremental` 的 object height 是 optional。使用目前 manifest 模型、dry servo 成功建立 mission 使用的 controller；**不是 constructor 缺高度 bug**。
- 既有 v21 jaw protections 已由 HEAD `67d29af` 合入，不能再次把已修的 v23-only jaw 問題列成現行 v21 缺陷。
- 沒有證據證明 repo 內有多個 motor TCP server 或多個 ROS odom publisher implementation。存在很多 client／獨立程序入口，server 和其他 odom 主線主要是外部文件引用。
- 沒有發現 Python AST syntax error，也沒有重現 segmentation fault/deadlock。這不等於硬體 thread/serial 安全已通過。
- URDF 與實際 LiDAR yaw、motor 左右輪映射、0.65/0.501 scale 的實測適用性、板端 watchdog、地圖版本，都不能僅用本機離線測試定案。
